# Defend My Cube

Jeu vidéo en 3D dont le but est la defense d'un cube, des enemis arrivent depuis l'extrémité d'un labyrinthe plat. Pour se faire le joueur a à disposition un grappin, permettant d’améliorer les déplacements, et des runes, lui permettant de lancer des projectiles sur les ennemis, sans oublié la possibilité de poser des tourelles de défense.
